HRWala — updating media and links

The original Figma layout and styling have been retained. The video and team photo areas remain the same size and position.

VIDEOS
1. Add each MP4 to public/videos/.
2. Open src/App.tsx and edit videoSources near the top.
3. Set the matching entry to a path such as '/videos/hr-consultants.mp4'.
The video fills the original gray frame and includes playback controls.

TEAM PHOTOS
1. Add each photo to public/assets/.
2. In src/App.tsx, edit teamPhotos near the top.
3. Set the matching entry to a path such as '/assets/team-member-01.png'.
Empty entries keep the existing gray photo placeholders.

LINKS AND CONTACT DETAILS
The navigation, button and footer links are added as transparent click areas in src/App.tsx near the end of Desktop1. Edit their href values to use your final portal and social profile URLs. WhatsApp and Gmail destinations are set on the footer click areas and the two forms.

FORMS
The contact form and newsletter button preserve the existing design and open a pre-filled Gmail draft addressed to hello@hrwala.net. The visitor must send the draft. Automatic saving or newsletter subscription requires a backend or mailing-list service.

HOSTINGER BUILD SETTINGS
Node.js: 22
Install: pnpm install --frozen-lockfile
Build: pnpm run build
Output directory: dist
